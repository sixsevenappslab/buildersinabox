## How to use this file

- Update the date at the top whenever something changes.
- One project per `###` section. Keep them under 20 lines each.
- If a project disappears (sunset, archived), move it to a `## Sunset` section at the bottom rather than deleting — history matters.
- Cross-link to specific spec files when relevant: `[FEAT-002](projects/<name>/specs/draft/FEAT-002.md)`.
