Your own AI dev box.

Plug in, code from your phone in 15 minutes — on any Ubuntu 24.04 machine you own.

curl -fsSL https://buildersinabox.com/install.sh | sudo bash
View on GitHub Read the script

What you get:

  • Claude Code (or another AI CLI) reachable from your phone over Tailscale — no port forwarding, no public IP.
  • A tmux session that survives disconnects. Pick up from the couch, a coffee shop, a flight.
  • A scaffolded workspace and a guided tutorial that gets you building your first project.

Bring your own Ubuntu 24.04 box — a mini PC, a homelab VM, or a VPS. Open source, MIT.
